# Padrão de Escrita para Requisitos Funcionais

Este documento define o modelo padrão para criação e atualização dos artefatos de **Requisitos Não Funcionais (RNF)**.

---

## Estrutura do Requisito Não Funcional

Cada requisito funcional deve ser documentado em um arquivo Markdown individual, utilizando o seguinte formato:

```md
### Título

**COMO** papel
**QUERO** ação
**PARA** finalidade

**Critérios de Aceitação**

- Critério 1
- Critério 2
- Critério 3
```

## Regras de Nomeação dos Arquivos

O nome do arquivo deve seguir o seguinte padrão:

RNF-<número>.md

## Numeração

A numeração dos requisitos deve ser sequencial (RNF-1, RNF-2, ...).

## Boas Práticas

Escreva de forma clara, objetiva e sem ambiguidades.

Utilize linguagem acessível para qualquer membro da equipe entender.

Sempre inclua critérios de aceite mensuráveis e testáveis.

Mantenha o escopo do requisito focado em uma funcionalidade específica.
